# Team Workflow

## Branch Strategy

- main contains production-ready code.
- Every new feature is developed in a feature branch.
- Branches are deleted after merge.

## Commit Convention

feat: New feature

fix: Bug fix

docs: Documentation

refactor: Code cleanup

chore: Maintenance work

## Pull Request

- At least one review before merging.
- Link issues using Closes #IssueNumber.

## GitHub Issues

Every task starts with an issue.
Each issue has:
- title
- description
- label
- assignee
